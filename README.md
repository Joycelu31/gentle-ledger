# 轻记账

React + Tailwind 的轻量记账 App 首页静态 UI。

## 运行

```bash
npm install
npm run dev
```

打开终端提示的本地地址，通常是 `http://127.0.0.1:5173`。

## 当前阶段

- 仅包含首页静态 UI
- 手机端优先
- 顶部资产入口按钮
- 中间三张概览卡片：今日支出、今日收入、月余额
- 底部固定输入框，占位文案为“记录一下今天？”

## 建议检查

- 手机宽度下三张卡片是否居中、留白是否舒适
- 底部输入框是否固定在底部且不遮挡主体内容
- 页面是否没有展示总资产
- 整体是否符合白色、清爽、温柔苹果感和森系陪伴风格
